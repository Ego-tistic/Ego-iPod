# Pro-Pods package repository

Add `https://ego-tistic.github.io/Pro-Pods-Repo/` to Zebra.

This repository contains the compiled package, APT metadata, and license.
The Pro-Pods source repository is separate and private.

Version 1.0.0 targets an iPod touch 6th generation (iPod7,1), iOS 12.5.8,
rootful. Device compatibility remains unverified. Do not install alongside
PodsGrant; the package declares that conflict.

Adapted from [PodsGrant](https://github.com/LNSSPsd/PodsGrant) by Ruphane,
upstream commit d727bf4f26474b6504be82fdbe0f391ff746db6d. See LICENSE.
